🌿 Rails AI Practice
A small Ruby on Rails app to experiment with Rails basics and AI features. Currently, it’s a simple product catalog for gardening items.

✨ Features
Gardening product list (with name, description, price, and image)

Image support via external URLs

Bootstrap 5 styling

Ready for future AI integrations (like description generation)

🚀 Getting Started
Requirements
Ruby 3.2+

Rails 7+

PostgreSQL

Setup
git clone https://github.com/lorena-davila2025/rails-ai-practice.git
cd rails-ai-practice

bundle install
rails db:setup
rails s
Visit http://localhost:3000 to see it running.

📸 Images
Products use image URLs (from Unsplash)

Note: currently the embeddings for products are commented out due to rate limit issues.
